# 付箋チェックリスト

Windows のデスクトップに常に表示しておける、付箋風のチェックリストです。
共有フォルダを使って、複数人でチェックリストを共有することもできます。

## 使い方

1. このリポジトリの [`StickyChecklistSetup.exe`](StickyChecklistSetup.exe) を開き、右上の「Download raw file」（↓）でダウンロードします。
2. ダウンロードした `StickyChecklistSetup.exe` を実行し、インストール先と自分の名前を入れて「インストール」を押します。
   デスクトップのショートカットと、Windows 起動時の自動起動を登録できます（管理者権限は不要）。

設定ファイル（`StickyChecklist.ini`）は、インストール先にまだ無ければ、インストーラーに入っているひな形（共有先・メンバーなどを設定済み）から作られます。名前を入れればその名前、空欄なら `unknown` になります（あとで ini の `UserName` を書き換えられます）。

> 署名の無い exe なので、Windows の SmartScreen や Microsoft Defender に止められることがあります。
> SmartScreen は「詳細情報」→「実行」で起動できます。Defender に検疫された場合は「Windows セキュリティ」→「保護の履歴」から許可してください。

## できること

- 項目の追加・チェック・編集・削除
  - 案件名（`【案件】` と表示）、内容、期日と時刻、ステータス、重要、共有、詳細メモ、添付ファイル
- 期日の表示（`10/31(残10日)`、残り3日以内は赤字）。時刻があれば日付の下に小さく表示（24時間表示）
- 「重要」マーク（重要な項目は上に表示）
- 項目ごとの詳細メモ（▼で開閉）
- **進捗管理**
  - ステータス: 未着手／進行中／確認待ち／差戻／修正／保留／完了（チェック□とは連動せず、どちらも手で変える）
  - ステータスの札を押すと「進捗・履歴」画面。ステータスと理由のコメントを記録（ステータスが同じでもコメントだけ記録できる）
  - 同じ項目の経過（日時・更新者・ステータス・コメント）を新しい順に一覧表示
- **添付ファイル**（エクセル・画像など）: 行へドラッグ＆ドロップ、右クリック、または編集画面から。行に 📎件数 が出る
- **更新の目印**: 他の人が更新した項目は色が付き、件数表示に「●更新○」。行を触ると消える
- 並べ替え（標準は「重要 → 期日が近い順」）
- 絞り込み（単語検索・完了/未完了・重要・期日・ステータス（複数選択・覚えておく）・共有）
- 行番号、件数表示（全○件（未○件：済○件））
- 最前面に固定（★）
- 自分用のチェックリストもネットワーク上に置けば、複数の端末で同時に使える

## 共有のしかた

1. 全員が読み書きできる共有フォルダ（ファイルサーバーなど）を用意します。
2. 各自の `StickyChecklist.ini`（exe と同じフォルダ。初回起動時に作られます）を開き、次を設定します。
   付箋のタイトルバーを右クリック →「設定ファイルを開く」でも開けます。
   ```ini
   UserName=山田
   SharedFile=\\fileserver\share\付箋チェックリスト\shared.txt
   Members=佐藤,鈴木,田中
   ```
3. 付箋を起動し直すと、入力欄の「共有先」と「共有」ボタンが使えるようになります。
   - 共有先（▾）で相手を選び（何も選ばなければ全員）、「共有」を ON にして追加すると共有されます。
   - 編集画面でも、共有する／しない と共有先を変えられます。
   - 共有した項目には「共有」マークが付き（全員に共有は青、共有先を選んだものは緑）、作成者・共有先・最終更新者はマウスを乗せると見られます。
4. 他の人の追加・変更・削除は、数秒ごと（`RefreshSeconds`）に自動で反映されます。

あらかじめ設定した `StickyChecklist.ini` を `StickyChecklistSetup.exe` と同じフォルダに置いて配ると、インストール時にその設定が引き継がれます。
ビルドするフォルダに `StickyChecklist.default.ini` を置いておくと、それがひな形としてインストーラーに埋め込まれます（チームのメンバー名などを書くので git には登録しません）。

> OneDrive・Teams・SharePoint の同期フォルダは、同時に書き込むと競合コピーができることがあるので、
> ファイルサーバーなどの共有フォルダをおすすめします。

## 設定ファイル（StickyChecklist.ini）

| 項目 | 内容 |
|---|---|
| `UserName` | 自分の名前（共有した項目の作成者として表示） |
| `PersonalFile` | 自分用チェックリストの保存先（既定は `checklist.txt`） |
| `SharedFile` | 共有チェックリストの保存先。空なら共有はオフ |
| `Members` | 共有先で選べるメンバー（カンマ区切り。共有ファイルに出てくる人は自動で追加） |
| `RefreshSeconds` | 共有の更新を確認する間隔（秒、既定 10） |
| `UpdateFrom` | 新しい版の配布元の exe。空なら `SharedFile` と同じフォルダの `StickyChecklist.exe` |

パスは絶対パス、または設定ファイルのあるフォルダからの相対パス。`%USERPROFILE%` なども使えます。

## 自動更新

配布元（`UpdateFrom`、既定は共有フォルダ）の `StickyChecklist.exe` を新しい版に置き換えると、各自の付箋は次に起動したときに入れ替わります。起動中の付箋は勝手には再起動しません。1 分以内に上部の件数表示の場所に青地・白文字で「Verが変更されました。反映するには更新アイコンを押して下さい」と出て ⟳ が青くなり、⟳ を押すと保存してから再起動して更新します。

お知らせの隣の ⓘ にマウスを乗せると変更内容が出ます。変更内容は配布元の exe と同じフォルダの `StickyChecklist.changes.txt` に、`[2026/10/27 16:20]`（配布した exe の日時）の見出しと「・」の行で、新しいものを上に書いておきます（自分の版より新しい見出しの分だけ表示）。

## データの形式

チェックリストのファイル（自分用・共有とも）は 1 行 1 項目のタブ区切りです。

```
id  完了  重要  期日  時刻  ステータス  案件  内容  詳細メモ  作成者  共有範囲  更新日時  更新者  ステータスコメント  添付
```

- 文字列の改行は `\n`、タブは `\t`、`\` は `\\` で保存
- 自分用・共有とも、変更した項目だけを id で書き換えます（書き込み中はロック。使用中なら少し待ち、だめならあとで自動で再試行）。同時に使っても他の変更は消えません
- 他の人・他の端末の変更は `RefreshSeconds` ごとに自動で読み込みます
- 旧形式のファイルは自動で新形式に変換されます（元のファイルは `checklist.txt.v1.bak` に残ります）

| 置き場所（チェックリストのファイルと同じフォルダ） | 内容 |
|---|---|
| `〇〇.history.txt` | 進捗の履歴（id・日時・更新者・ステータス・コメント）。追記のみ |
| `〇〇.numbers.txt` | 項目の番号（id・番号）。一度付けた番号は絞り込み・並べ替えでも変わらず、全員で同じ番号になる。共有しているときは共有ファイルの隣に 1 つだけ作り、自分用の項目も同じ通し番号にする |
| `attachments\<id>\` | 添付ファイル |

自分用 ⇔ 共有 を切り替えると、履歴と添付も一緒に移ります。

ウィンドウ位置・並べ替え設定は `%APPDATA%\StickyChecklist\data.json` に保存されます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `StickyChecklist.ps1` | アプリ本体（PowerShell + WinForms） |
| `Launcher.cs` | 本体を埋め込んで起動する `StickyChecklist.exe` のソース |
| `Setup.cs` | インストーラー `StickyChecklistSetup.exe` のソース |
| `Shortcut.cs` | ショートカット作成（両方の exe で共通） |
| `build.ps1` | exe を作り直すスクリプト |
| `StickyChecklist.ico` | アイコン |

## ビルド

`StickyChecklist.ps1` などを変更したら、次を実行して exe を作り直します（Windows 標準の .NET Framework のコンパイラを使用）。

```
powershell -ExecutionPolicy Bypass -File build.ps1
```
